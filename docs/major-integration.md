# MAJOR 合併決議

整合 `feature/jin-route` 與 `murse-V2-all-v3`，依指定功能歸屬解決衝突。

## 保留 JIN

- 每台車的保養／退役規則、缺少保養資料時的提醒，以及含回倉的預估里程判斷。
- 出車前酒測與安全檢查、檢查通過後的出車里程，以及出車／點交的前後順序。
- 司機任務日期查詢、異常案件回報、路線偏離與後台處理。
- V1～V14 資料庫遷移，V12 移除噸位規則表與 `vehicles.tonnage`；不恢復 V2 噸位規則。

## 保留 V2

- 營運報表與歷史查詢：人員、車輛、訂單、異常、倉庫，支援日／週／月／年。
- 共用登入、主管導覽與畫面；人車資源司機分頁及所屬倉庫管理。
- 事後補請假：班表日曆、多日期、整日／部分時段、證明附件，以及審核紀錄。

## 整合接點

- 報表讀取 JIN 的安全檢查資料，只有同日、同司機、同車、同路線版本且未作廢的紀錄有效。
- 補齊事後補請候選日期與批次 API，日曆顯示待審申請與已選日期。
- 司機轉倉通知主管看板更新；新指派／發布以每條路線的所屬倉庫檢查。
- 配送進度與發布狀態分開，避免已結束的草稿被誤認為已發布。
- 新增 V15 `drivers.warehouse_id`，接續 JIN 結構。舊司機不猜測所屬倉庫，由主管指定。

## 資料庫注意事項

已使用獨立測試庫驗證全套 Flyway 遷移與整合測試，沒有修改原本營運資料庫。
若現有資料庫套過另一分支同版號的遷移、手動新增欄位或保存不同 checksum，
部署前須備份並核對 Flyway 歷程，不可直接修 checksum 或讓兩組遷移同時執行。

本機合併提交不等於已部署或推送遠端。驗證輸出、測試資料庫工具及截圖不列入程式提交。
