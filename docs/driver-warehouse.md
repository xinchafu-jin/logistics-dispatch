# 司機所屬倉庫

人車資源的「司機」分頁提供新增、編輯、狀態／倉庫篩選及姓名、帳號、電話、倉庫搜尋。
每位司機可記錄所屬倉庫；可修改工作時間、休息時間、加班上限及帳號啟用狀態。所屬倉庫不限制司機接其他倉的訂單。
保留停用帳號與配送歷史，不提供刪除歷史司機的操作。

新增司機必須指定啟用中的倉庫。既有司機可轉倉，已發布路線不會被改寫；
未發布的草稿仍可使用已轉倉司機，不必重新指派。
拖曳看板提供全部倉庫的在職司機，仍遵守當日班表、請假與跨倉同日重複派車檢查。
休假、請假、未排班或班表未發布的司機不能新指派；打卡由司機實際開始出車時檢查，
不以「現在已打卡」限制未來日期的預排。發布不檢查司機所屬倉庫是否與路線相同。
主管存檔後以資源推播更新其他管理員的司機選單。司機端「個人資料」也顯示所屬倉庫。

資料庫欄位 `drivers.warehouse_id` 對應 `warehouses.id`，外鍵禁止刪除仍有司機的倉庫。
舊資料保持空值，畫面提示「待設定所屬倉庫」，不以歷史配送路線推測員工歸屬。
主管可補上所屬倉庫，但舊司機即使未設定也可安排新路線。原本已發布路線照常保留。

新增仍使用既有後端規則：台灣身分證字號為初始密碼，後端檢查格式／檢查碼並保存 BCrypt。
編輯司機不傳送或重設密碼。
